# 🗡️ Grid Soul: Путь Гладиатора

**Grid Soul** — это динамичный 2D Top-Down экшен, разработанный на платформе **Windows Forms (C#)**. Пройдите путь от простого гладиатора в тренировочной яме до легендарного воина, бросившего вызов самому Императору. 

В игре исторический реализм переплетается с напряженным геймплеем: с каждым уровнем вам предстоит осваивать новое оружие и сталкиваться с опасными противниками.

---

## 📖 Сюжетная Прогрессия

История разделена на 5 уровней. Перед каждым боем вы получаете информацию о своем снаряжении, полученном от тайных союзников, а также о тактике врагов:

* **Уровень 1: Тренировочная яма**
  * **Оружие:** Гладиаторский нож (быстрый, малый радиус).
  * **Враги:** Голодные тигры (только ближний бой).
* **Уровень 2: Первый триумф**
  * **Оружие:** Охотничье копье (наносит большой урон, редкие выстрелы, летит по прямой).
  * **Враги:** Воины с мечами.
* **Уровень 3: Противостояние колесницам**
  * **Оружие:** Тяжелый Пилум (метательный снаряд, замедляет колесницы).
  * **Враги:** Колесницы (стреляют дротиками).
* **Уровень 4: Гнев Преторианцев**
  * **Оружие:** Фалкс (изогнутое двуручное лезвие, наносит урон по широкой дуге).
  * **Враги:** Элитные Преторианцы (пытаются зажать в угол).
* **Уровень 5: Финал с Императором**
  * **Оружие:** Мастерство Арены (возможность переключаться между Пилумом и Фалксом, защита щитом).
  * **Враги:** Император (сложный босс с несколькими фазами).

---

## 🎮 Особенности Игры

* **Аутентичный арсенал**: У каждого оружия уникальные механики — дальность, скорость, и тип атаки.
* **Тактика боя**: Возможность менять оружие на 5 уровне с помощью клавиш `Q` или `1-2`.
* **Увеличенные предметы лечения**: Сумки с травами увеличены в 2 раза, чтобы их было удобно подбирать в пылу битвы.
* **Сюжетные вставки**: Перед каждым уровнем отображается окно с описанием вашего оружия и историческим контекстом.

## 🛠️ Технический Стек

* **Язык**: C# / .NET Framework
* **Платформа**: Windows Forms
* **Графика**: GDI+, оптимизированная для плавной отрисовки спрайтов.
* **Оптимизация**: Использование безопасных циклов для предотвращения ошибок при работе со списками врагов и снарядов.
